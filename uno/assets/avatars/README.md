# Local mix-and-match avatar patterns

These eight small SVG masks were drawn for the local iroh adaptation. They contain no scripts, external references, or personal images. Palette values and pattern names are allowlisted in `../../profiles.mjs`.

The orange/dots combination still displays the unchanged original ScuffedUNO default avatar. All combinations retain the original avatar border from `../scuffeduno/`. See that directory's provenance and redistribution-permission warning; the new masks do not confer rights to the original assets.

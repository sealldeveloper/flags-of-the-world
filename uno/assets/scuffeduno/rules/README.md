# Original lobby rule artwork

These five unmodified 512×512 PNG illustrations come from the original ScuffedUNO lobby: Stacking, Force Play, Draw To Play, Jump In, and 7–0. `provenance.json` records exact public source URLs, fetch timestamps, byte lengths, and SHA-256 hashes.

The local selector follows the original three-column grid, 96-pixel desktop illustrations, four-pixel grey borders, short captions, and grayscale/70%-opacity off state. Native checkboxes, visible keyboard focus, a small checked indicator, and linked rule descriptions keep the adapted controls accessible. Narrow layouts shrink the tiles without clipping them.

No original application code is executed. All images are served from this static site. The original Public toggle, team modes, authentication, adverts, and chat are not reproduced: this port has private iroh rooms and its own documented rule semantics.
